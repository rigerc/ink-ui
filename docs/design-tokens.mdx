---
title: 🎨 Design Tokens
description: The shared colour palette and spacing scale that keep every screen consistent.
---

Every component is built on the same set of design tokens. Import `colors`, `palette`, `priorityColors` and `spacing` to keep your own components aligned with the design system.

```ts
import { colors, palette, priorityColors, spacing } from "@kud/ink-ui";
import type { Color, Palette, PriorityColor, Spacing } from "@kud/ink-ui";
```

## 🌈 Colours

| Token                   | Value     | Semantic use                                     |
| ----------------------- | --------- | ------------------------------------------------ |
| `colors.accent`         | `#FF8C00` | Primary highlight, cursor, active tab            |
| `colors.secondary`      | `#999999` | Context beside the answer                        |
| `colors.muted`          | `#75767E` | Dimmed text, table headers                       |
| `colors.dim`            | `#5C5E73` | Rules and separators only, never text            |
| `colors.success`        | `#5FD7A7` | Positive states, with `✓` or a word              |
| `colors.error`          | `#FF5364` | Failures and errors, with `✗` or a word          |
| `colors.warning`        | `#FFB400` | Caution states, with `⚠` or a word               |
| `colors.info`           | `#89DDFF` | Neutral informational, with `ℹ` or a word        |
| `colors.pending`        | `#75767E` | Queued or waiting, no hue                        |
| `colors.group`          | `#C792EA` | Container header (an epic)                       |
| `colors.ticket`         | `#FFCB6B` | Ticket key, such as `SHOP-1234`                  |
| `colors.pr`             | `#FF8C00` | PR or issue number, such as `#123`               |
| `colors.link`           | `#82AAFF` | Links and URLs                                   |
| `colors.added`          | `#4ADE80` | Diff additions, such as `+42`                    |
| `colors.removed`        | `#FF6B6B` | Diff deletions, such as `-7`                     |
| `colors.selection`      | `#30364A` | Selected row ground                              |
| `colors.track`          | `#2B323D` | Unfilled ground: progress track, skeleton bars   |
| `colors.trackHighlight` | `#6B7480` | Skeleton shimmer crest                           |

Every value is drawn from `palette`, tuned to the dark ground `#1a1b27`: dark-only, truecolour assumed, and chalk downsamples on a 256-colour terminal. `priorityColors` steps priority by lightness: `highest` and `high` `#E4E4EC`, `medium` `#999999`, `low` and `lowest` `#75767E`.

`Color` is the union of these token values, so you can type props that accept a palette colour.

```tsx
import { Text } from "ink";
import { colors } from "@kud/ink-ui";

<Text color={colors.accent}>Highlighted</Text>;
```

## 📐 Spacing

| Token        | Value | Description                        |
| ------------ | ----- | ---------------------------------- |
| `spacing.xs` | `1`   | Tight gap between inline elements  |
| `spacing.sm` | `2`   | Small margin between grouped items |
| `spacing.md` | `3`   | Standard section margin            |
| `spacing.lg` | `4`   | Large gap between major sections   |

`Spacing` is the union of these values, suitable for Ink's `margin`, `padding`, and `gap` props.

```tsx
import { Box } from "ink";
import { spacing } from "@kud/ink-ui";

<Box marginBottom={spacing.md}>…</Box>;
```


## Symbols, borders and motion

The token system also provides semantic terminal glyphs, accessible ASCII
fallbacks, border presets, and motion settings. These extend the existing
`src/tokens.ts` module; **no theme provider or alternate palette is required**.

```tsx
import {
  colors,
  spacing,
  symbols,
  asciiSymbols,
  borders,
  motion,
} from "@kud/ink-ui"

// Stepper uses colors.success / colors.accent / colors.muted and symbols.
<Text color={colors.success}>{symbols.success} Completed</Text>
<Box borderStyle={borders.base} borderColor={colors.muted} padding={spacing.xs}>
  <Text>Ready</Text>
</Box>

// Fallback for environments that only support ASCII glyphs:
<Text>{asciiSymbols.pointer} Pending</Text>
```

The symbol keys include `success`, `error`, `warn`, `info`,
`active`, `pending`, `pointer`, checked/unchecked boxes, `bullet`,
`nestedBullet` / `nestedBulletEmpty`, `caret`, `ellipsis`,
`line`, `verticalLine`, `rule`, and filled/empty bars. `borders` defines `base`, `focus`,
and `ascii` styles for Ink's `borderStyle`. `motion` supplies Unicode
and ASCII spinner frames plus `intervalMs` (spinner animation) and
`skeletonIntervalMs` (skeleton shimmer). `Spinner` accepts `ascii` to
switch to the ASCII frame set without changing other components. Consumers choose their appropriate glyph set; the library's
existing `setIconMode` remains available for Nerd Font icons.

These semantic tokens are used throughout the existing components:
`StatusMessage` and `Alert` resolve icons through `statusVariant`;
`Select`, `MultiSelect`, `SelectableRow`, `Toggle`, `Switch`,
`ToggleSwitch`, `UnorderedList`, `Panel`, and `CommandPalette`
share cursor/selection symbols; `ProgressBar` and `SkeletonBar`
use the bar glyph; `Page`, `Tabs`, `FilterBar`, and
`CommandPalette` use line/caret tokens; bordered components use
`borders`; and `Spinner` / `SkeletonRows` use `motion`.
Specialized brand icons and keyboard hints remain caller-defined.

The existing `colors`, `softColors`, `tonalColors`,
`tonalStrongColors`, `priorityColors`, and `spacing` are unchanged.
`NO_COLOR` continues to be handled by Ink/terminal color support; it
does not change the semantic meaning of the symbols.
