title: ⌨️ FooterHints
description: Wrapped keyboard shortcut hints for interactive screens.
---

`<FooterHints>` renders consistent keyboard shortcut help for interactive terminal screens.

```tsx
import { FooterHints } from "@rigerc/ink-ui";
import type { Hint } from "@rigerc/ink-ui";
```

## 🔧 Props

| Prop    | Type     | Description                     |
| ------- | -------- | ------------------------------- |
| `hints` | `Hint[]` | Tuples of key label and meaning |

## 💡 Examples

```tsx
<FooterHints
  hints={[
    ["↑↓", "navigate"],
    ["↵", "select"],
    ["q", "quit"],
  ]}
/>
```

## Host appearance and automatic tail

`page="root"` appends Help and Quit; `page="nested"` adds Back first. `help={false}` omits Help. `backKey` defaults to `⌫` and can be `Esc` for ASCII output; caller-supplied hint keys are never rewritten. `tailHints(page, help, backKey)` provides the same tail without rendering.

`keyColor` defaults to white; `labelColor` defaults to terminal foreground. Both accept `null` to explicitly use terminal foreground or an Ink color supplied by the host. `dimLabels` defaults to true; use false for normal-intensity labels. `columnGap` defaults to 2 and can be reduced when budgeting a narrow footer. Wrapping does not insert blank rows.

See [widget appearance](./widget-appearance).
