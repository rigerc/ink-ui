`<Spinner>` renders an animated dots spinner in the accent colour, with an optional dimmed label beside it. Its frames come from the shared motion tokens.

```tsx
import { Spinner } from "@rigerc/ink-ui";
```

## 🔧 Props

| Prop    | Type     | Default | Description                               |
| ------- | -------- | ------- | ----------------------------------------- |
| `label` | `string` | —       | Optional text rendered beside the spinner |

The spinner glyph is coloured with `colors.accent` (`#FF8C00`).

## 💡 Examples

```tsx
<Spinner label="Building…" />
```

```tsx
<Spinner />
```

## Motion and host colors

`ascii` chooses the ASCII frame set independently of color. `animate={false}`, `NO_MOTION` or `REDUCE_MOTION` displays a static pending glyph without creating a timer; `staticFrame` overrides that glyph. The label remains visible so static progress is meaningful.

`color` and `labelColor` accept host colors or `null` for terminal-default foreground. Omitted colors retain the existing defaults. `dimLabel={false}` uses normal-intensity label text. See [widget appearance](./widget-appearance).
